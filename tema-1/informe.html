II. Análisis de resultados

Prueba en navegador: al completar nombre, correo y mensaje, se mostró «Datos validados, Ana. Demostración completada; no se enviaron datos». La imagen local y los controles etiquetados se visualizaron.

El documento organiza la presentación mediante elementos semánticos. El atributo alt describe la ilustración y los label permiten identificar los campos. required y type="email" incorporan validación nativa. El pequeño script evita que el POST de ejemplo apunte a un recurso inexistente en GitHub Pages y muestra una confirmación local.

III. Conclusiones

  1. HTML permite separar y ordenar el contenido con encabezados, secciones y formularios.
  2. Las etiquetas asociadas y el texto alternativo hacen identificables los controles y la imagen.
  3. Un formulario estático puede validar campos, pero necesita un servicio adicional para enviar o almacenar mensajes.

Código de la solución

Los archivos originales también están incluidos en la carpeta de este tema.

demo.js
// Demostración local: no se realiza una solicitud POST a un servidor.
document.querySelector('form').addEventListener('submit', function(event) {
  event.preventDefault();
  const nombre = document.getElementById('nombre');
  const estado = document.getElementById('estado');
  if (!nombre.value.trim()) { estado.textContent = 'Escribe tu nombre, sin dejar solo espacios.'; nombre.focus(); return; }
  estado.textContent = 'Datos validados, ' + nombre.value.trim() + '. Demostración completada; no se enviaron datos.';
});
