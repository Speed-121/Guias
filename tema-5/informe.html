II. Análisis de resultados

Revisión en navegador de escritorio: Bootstrap se cargó desde los archivos incluidos; se visualizaron las tres columnas, navegación, tarjeta y formulario. No se comprobó el menú plegable en un ancho móvil.

La grilla divide el ancho en doce partes: cada col-md-4 ocupa cuatro, por lo que caben tres columnas desde el breakpoint md. navbar-expand-lg mantiene el menú plegado por debajo de lg y el bundle habilita su apertura. La hoja personalizada se carga al final para ajustar la presentación mediante la cascada sin cambiar los archivos originales del framework.

III. Conclusiones

  1. Bootstrap reduce el código de estilos necesario mediante clases y componentes reutilizables.
  2. El sistema de doce columnas produce distribuciones que cambian según el ancho de pantalla.
  3. Una hoja personalizada permite adaptar el diseño manteniendo intacto el framework.

// Demostración local: no se realiza una solicitud POST a un servidor.
document.querySelector('form').addEventListener('submit', function(event) {
  event.preventDefault();
  const nombre = document.getElementById('nombre');
  const estado = document.getElementById('estado');
  if (!nombre.value.trim()) { estado.textContent = 'Escribe tu nombre, sin dejar solo espacios.'; nombre.focus(); return; }
  estado.textContent = 'Datos validados, ' + nombre.value.trim() + '. Demostración completada; no se enviaron datos.';
});
