I. Datos y registros de la práctica

Se programaron los elementos indicados en la guía. La tabla describe la implementación y los casos de comprobación; las pruebas de navegador efectivamente realizadas se documentan en VERIFICACION.txt.

Elemento o casoImplementación o entradaComportamiento previsto
Entrada vacíaTexto compuesto solo por espacios.No se crea ningún elemento li.

Eliminar tareaEliminar la primera tarea.Solo se retira el li correspondiente.

II. Análisis de resultados

Pruebas en navegador: entrada vacía → 0 tareas; agregar «Estudiar HTML» → 1 tarea; agregar «Practicar JavaScript» → 2 tareas; eliminar la primera → 1 tarea y la segunda permanece visible.

Cada envío válido crea un li y su botón mediante createElement y appendChild. La función del botón conserva una referencia al li que debe eliminar, de modo que removeChild retira únicamente esa tarea. trim evita tareas vacías y textContent impide interpretar el texto ingresado como etiquetas HTML. La lista solo existe en memoria durante la visita.

III. Conclusiones

  1. El DOM permite agregar y quitar tareas sin recargar la página.
  2. Cada botón de eliminación puede actuar sobre un elemento específico mediante una referencia.
  3. Validar espacios y utilizar textContent mejora la calidad de la entrada y evita interpretar etiquetas.

app.js
const input = document.getElementById('tareaInput');
const boton = document.getElementById('agregarBtn');
const lista = document.getElementById('listaTareas');
const estado = document.getElementById('estado');
function actualizarContador() {
  const total = lista.children.length;
  document.getElementById('contador').textContent = total + (total === 1 ? ' tarea' : ' tareas');
}
document.getElementById('tareaForm').addEventListener('submit', function(event) {
  event.preventDefault();
  const textoTarea = input.value.trim();
  if (!textoTarea) { estado.textContent = 'Escribe una tarea antes de agregarla.'; input.focus(); return; }
  const nuevaTarea = document.createElement('li');
  const texto = document.createElement('span');
  texto.textContent = textoTarea; // Se trata como texto, nunca como HTML ejecutable.
  const btnEliminar = document.createElement('button');
  btnEliminar.type = 'button';
  btnEliminar.textContent = 'Eliminar';
  btnEliminar.setAttribute('aria-label', 'Eliminar tarea: ' + textoTarea);
  nuevaTarea.appendChild(texto);
  nuevaTarea.appendChild(btnEliminar);
  lista.appendChild(nuevaTarea);
  input.value = '';
  estado.textContent = 'Tarea agregada: ' + textoTarea;
  actualizarContador(); input.focus();
  btnEliminar.addEventListener('click', function() {
    lista.removeChild(nuevaTarea);
    estado.textContent = 'Tarea eliminada: ' + textoTarea;
    actualizarContador(); input.focus();
  });
});
