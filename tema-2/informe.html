I. Datos y registros de la práctica

Se programaron los elementos indicados en la guía. La tabla describe la implementación y los casos de comprobación; las pruebas de navegador efectivamente realizadas se documentan en VERIFICACION.txt.

Elemento o casoImplementación o entradaComportamiento previsto
Cabecera y tarjetasdisplay: flex; flex-wrap: wrap.Reglas incluidas en styles.css.
Galeríadisplay: grid con auto-fit y minmax.Tres imágenes locales con alt.
MóvilMedia query max-width: 768px.Cabecera, menú y tarjetas pasan a columna.

II. Análisis de resultados

Revisión en navegador de escritorio: se visualizaron tres tarjetas en una fila, tres imágenes en la galería, el menú y la sección de contacto. El comportamiento móvil está definido en CSS; no se realizó una prueba con un dispositivo móvil.

Flexbox distribuye componentes en una dimensión, mientras que Grid organiza la galería en columnas adaptables. El cambio a una disposición vertical hasta 768 px evita que el menú y las tarjetas se compriman en móviles. Las imágenes conservan su proporción y los controles tienen una anchura limitada por el contenedor.

III. Conclusiones

  1. La hoja externa centraliza los estilos y facilita modificar la presentación sin cambiar el contenido.
  2. Flexbox y Grid resuelven necesidades distintas: distribución de componentes y organización de la galería.
  3. Las media queries permiten reorganizar la interfaz para pantallas pequeñas.

styles.css
/* Modelo de caja, cabecera Flexbox, tarjetas Flexbox y galería Grid. */
* { box-sizing: border-box; }
body { font-family: Arial, sans-serif; background: #f4f4f4; color: #333; }
.cabecera { display: flex; justify-content: space-between; align-items: center; gap: 20px; background: #004080; color: white; padding: 15px 20px; border-radius: 10px; }
.cabecera h2 { color: white; }
nav ul { display: flex; gap: 15px; list-style: none; padding: 0; }
nav a { color: white; font-weight: bold; text-decoration: none; }
nav a:hover { text-decoration: underline; }
.contenedor-tarjetas { display: flex; gap: 20px; flex-wrap: wrap; justify-content: space-evenly; margin: 30px 0; }
.tarjeta { background: white; padding: 20px; border-radius: 10px; box-shadow: 0 2px 6px rgba(0,0,0,.1); width: 280px; max-width: 100%; }
.tarjeta h2 { color: #004080; }
.galeria { display: grid; grid-template-columns: repeat(auto-fit, minmax(min(200px, 100%), 1fr)); gap: 20px; margin: 30px 0; }
.galeria img { width: 100%; border-radius: 8px; }
@media screen and (max-width: 768px) {
 .cabecera { flex-direction: column; text-align: center; }
 nav ul { flex-direction: column; }
 .contenedor-tarjetas { flex-direction: column; align-items: center; }
}
demo.js
// Demostración local: no se realiza una solicitud POST a un servidor.
document.querySelector('form').addEventListener('submit', function(event) {
  event.preventDefault();
  const nombre = document.getElementById('nombre');
  const estado = document.getElementById('estado');
  if (!nombre.value.trim()) { estado.textContent = 'Escribe tu nombre, sin dejar solo espacios.'; nombre.focus(); return; }
  estado.textContent = 'Datos validados, ' + nombre.value.trim() + '. Demostración completada; no se enviaron datos.';
});
