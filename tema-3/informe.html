I. Datos y registros de la práctica

Se programaron los elementos indicados en la guía. La tabla describe la implementación y los casos de comprobación; las pruebas de navegador efectivamente realizadas se documentan en VERIFICACION.txt.

Elemento o casoImplementación o entradaComportamiento previsto
Campos vacíosNombre="", correo="", edad="".Rechazo: todos los campos son obligatorios.
Correo inválidoAna, ana, 20.Rechazo: correo electrónico inválido.
Menor de edadAna, ana@example.com, 17.Rechazo: edad mínima de 18 años.
Datos válidosAna, ana@example.com, 18.Validación correcta; sin envío real.

II. Análisis de resultados

Pruebas en navegador: campos vacíos → rechazo; edad 17 → rechazo por edad mínima; edad 18 y correo válido → confirmación local; correo «ana» → rechazo por formato. Los mensajes observados coinciden con los casos principales.

El evento submit se cancela con preventDefault. La función validarDatos revisa campos vacíos, formato de correo y edad. Se usa Number en lugar de parseInt para no aceptar accidentalmente edades decimales truncadas. El resultado aparece en un área de estado accesible. Estas comprobaciones del cliente no sustituyen una validación de servidor en una aplicación real.

III. Conclusiones

  1. La validación impide continuar con campos incompletos, correos incorrectos y edades menores de 18.
  2. Las funciones y el evento submit organizan las reglas y evitan la recarga de la página.
  3. Un mensaje visible permite conocer el resultado sin afirmar un envío que no ocurrió.

// Función separada para validar sin confundir un campo vacío con cero.
function validarDatos(nombre, correo, edadTexto) {
  if (!nombre.trim() || !correo.trim() || !edadTexto.trim()) return 'Todos los campos son obligatorios.';
  if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(correo.trim())) return 'Ingresa un correo electrónico válido.';
  const edad = Number(edadTexto);
  if (!Number.isInteger(edad)) return 'Ingresa una edad válida en años enteros.';
  if (edad < 18) return 'Debes tener al menos 18 años para enviar el formulario.';
  return '';
}
document.getElementById('contactoForm').addEventListener('submit', function(event) {
  event.preventDefault();
  const nombre = document.getElementById('nombre');
  const correo = document.getElementById('correo');
  const edad = document.getElementById('edad');
  const estado = document.getElementById('estado');
  const error = validarDatos(nombre.value, correo.value, edad.value);
  for (const campo of [nombre, correo, edad]) campo.removeAttribute('aria-invalid');
  estado.className = 'status ' + (error ? 'error' : 'success');
  estado.textContent = error || 'Formulario validado correctamente. Gracias por participar. Demostración: no se enviaron datos.';
  if (error) {
    const campo = !nombre.value.trim() ? nombre : (!correo.value.trim() || !correo.validity.valid || !/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(correo.value.trim())) ? correo : edad;
    campo.setAttribute('aria-invalid', 'true'); campo.focus();
  }
});
